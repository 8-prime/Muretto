Muretto
GitHub

A launcher and content manager for Assetto Corsa

For Linux and Windows. Set up a session and drive, browse online servers, install mods and see which server your friends are on.

Download for Linux x86_64 Download for Windows x86_64

On Linux, make the file executable with chmod +x muretto-linux-x86_64. On Arch Linux you can install muretto-bin from the AUR. Older versions are on the releases page.

What it does

Muretto finds Assetto Corsa in your Steam library and starts it directly. On Linux it runs the game through Proton.

Quick drive

Choose car, track, session, weather and assists from your installed content and start the game.

Online servers

Browse servers with filters and ping. If a server needs cars or tracks you don't have, Muretto installs them from the server's download link.

Mods

Installs Custom Shaders Patch, Pure and other mods. Muretto records every file it adds, so updates and removals leave nothing behind and game files a mod replaced are restored.

Friends

Share a group code to see which server each friend has open. Join with one click, or follow a friend to join wherever they go.

Group server

This server connects Muretto friend groups. Group data is encrypted with a key derived from the group code; the server only forwards it and cannot read it. The server is open source and you can host your own.
